# Security Policy

## Reporting Security Issues

To report a security issue in this SDK, please contact support@graphorlm.com.

Please do not open a public issue for a vulnerability.

## Responsible Disclosure

We appreciate the efforts of security researchers. If you believe you have found a security vulnerability, please
allow us a reasonable amount of time to investigate and address the issue before making any information public.

## Reporting Non-SDK Related Security Issues

For security issues in the services or products provided by Graphor, or for any questions about their security,
please contact support@graphorlm.com.

---

Thank you for helping us keep the SDKs and systems they interact with secure.
